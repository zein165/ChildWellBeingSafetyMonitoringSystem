# Child Wellbeing Safety Monitoring - Mobile Template

React Native + TypeScript starter template with modular architecture for:
- Digital activity monitoring
- App inventory monitoring
- Location and outside activity
- Timeline and reporting
- Rule and alert system

## Quick start
1. `npm install`
2. Android: `npm run android`
3. iOS: `npm run ios`

## Notes
- Several collectors rely on platform-specific native capabilities and are scaffolded as service stubs.
- Rule evaluation and timeline persistence are already wired in Redux.
